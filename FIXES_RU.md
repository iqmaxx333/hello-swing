# ИСПРАВЛЕНИЯ МОДА SWINGANIMATION

## ЧТО БЫЛО СЛОМАНО:

### Проблема 1: Еда уходит за голову
При поедании еды (яблоко, хлеб и т.д.) предмет исчезал за камерой и его не было видно.

**Причина:** 
- Неправильный расчет позиции при использовании предметов
- Слишком большие углы поворота (до 90 градусов)
- Отсутствие специальной обработки для еды

### Проблема 2: Другие предметы могли уходить за камеру
При взмахе любыми предметами они могли уйти слишком далеко назад.

**Причина:**
- Нет ограничения максимального угла поворота
- Не учитывается расстояние до камеры

## ЧТО ИСПРАВЛЕНО:

### ✅ Исправление 1: Специальная анимация для еды

В файле `HeldItemRendererMixin.java`:

```java
// Проверяем, ест ли игрок
if (player.getItemUseTime() > 0 && player.isUsingItem()) {
    // Держим еду перед камерой, а не за головой!
    matrices.translate(handSide * 0.1F, 0.3F, -0.6F);
    
    // Поворачиваем к лицу
    matrices.multiply(RotationAxis.POSITIVE_Y.rotationDegrees(handSide * 15.0F));
    matrices.multiply(RotationAxis.POSITIVE_X.rotationDegrees(-10.0F));
}
```

**Результат:** Еда всегда видна, находится перед камерой!

### ✅ Исправление 2: Ограничение углов поворота

В файле `SwingAnimationTransformer.java`:

```java
// Старый код (ПЛОХО):
float rotationX = -swingAmount * intensity * 90.0F; // До 90 градусов!

// Новый код (ХОРОШО):
float rotationX = -swingAmount * intensity * 60.0F; // Максимум 60 градусов
rotationX = Math.min(rotationX, 60.0F); // Дополнительная защита
rotationX = MathHelper.clamp(rotationX, -60.0F, 10.0F); // Точный контроль
```

**Результат:** Предметы НИКОГДА не уходят за камеру!

### ✅ Исправление 3: Новая функция для использования предметов

Добавлена специальная функция `applyItemUseTransformation()`:

```java
public static void applyItemUseTransformation(MatrixStack matrices, 
                                              float useProgress, 
                                              boolean isRightHand, 
                                              boolean isFood) {
    if (isFood) {
        // Специальная логика для еды
        matrices.translate(
            -handMultiplier * 0.2F * eatProgress, // К центру
            0.2F + wave,                          // Вверх
            -0.5F                                 // ПЕРЕД камерой!
        );
    }
}
```

### ✅ Исправление 4: Улучшенные типы анимаций

Все 4 типа анимации переделаны с безопасными углами:

- **CLASSIC**: максимум 60° (было 90°)
- **SMOOTH**: максимум 50° (было 80°)
- **DYNAMIC**: максимум 55° (было 85°)
- **REALISTIC**: максимум 45° (было 70°)

### ✅ Исправление 5: Новые настройки в конфиге

Добавлены 3 новых параметра в `SwingAnimationConfig.java`:

```java
public boolean fixFoodAnimation = true;      // Исправление для еды
public boolean preventHeadClipping = true;   // Защита от ухода за голову
public float maxRotationAngle = 60.0F;       // Настраиваемый лимит
```

Теперь можно настроить максимальный угол от 30° до 90°!

## КАК СОБРАТЬ МОД:

### Вариант 1: С помощью Gradle (рекомендуется)

1. Распакуйте `swinganimation_fixed_source.zip`
2. Откройте терминал в папке мода
3. Выполните команды:
   ```bash
   chmod +x gradlew
   ./gradlew build
   ```
4. Готовый JAR будет в `build/libs/swinganimation-1.21.4-fixed.jar`

### Вариант 2: С помощью IDE (IntelliJ IDEA)

1. Распакуйте архив
2. Откройте папку в IntelliJ IDEA
3. Дождитесь индексации Gradle
4. Выполните задачу Gradle: `build`

## КАК УСТАНОВИТЬ:

1. Скопируйте JAR файл в папку `.minecraft/mods/`
2. Убедитесь, что установлены:
   - Fabric Loader 0.16.9 или новее
   - Fabric API 0.110.5 или новее
3. Запустите Minecraft 1.21.4

## НАСТРОЙКА:

Конфиг находится в `.minecraft/config/swinganimation.json`

### Базовые настройки:
```json
{
  "enabled": true,              // Включить/выключить мод
  "animationType": "SMOOTH",    // CLASSIC, SMOOTH, DYNAMIC, REALISTIC
  "rotationIntensity": 1.0,     // 0.1 - 2.0 (сила анимации)
  "swingSpeed": 1.0             // 0.5 - 2.0 (скорость анимации)
}
```

### Новые настройки исправлений:
```json
{
  "fixFoodAnimation": true,        // Исправить анимацию еды (ВАЖНО!)
  "preventHeadClipping": true,     // Не давать предметам уходить за камеру
  "maxRotationAngle": 60.0         // Максимальный угол (30-90)
}
```

## ТЕСТИРОВАНИЕ:

### Как проверить исправления:

1. **Тест еды:**
   - Возьмите яблоко
   - Зажмите правую кнопку мыши
   - ✅ Яблоко должно быть перед камерой

   - ✅ Анимация должна быть плавной

3. **Тест разных предметов:**
   - Протестируйте: лук, щит, блоки, инструменты
   - ✅ Все должно работать корректно
